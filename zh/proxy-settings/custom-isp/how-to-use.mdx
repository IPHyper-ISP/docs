---
title: "如何使用IPHyper "
---

定制静态住宅 IP 是独享型 IP，有效期内仅分配给一个用户，网络环境更纯净稳定。本指南带你从查看 IP 列表、获取代理参数到管理续费，一步步上手。

## **查看IP列表**

购买成功后，登录管理面板进入「IP 列表」，可查看每条 IP 的详细信息：

| 字段 | 说明 |
| :-- | :-- |
| IP / 端口 | 代理IP与端口 |
| 代理参数 | 可直接复制的完整代理字符串 |
| 国家 / 地区 | IP 归属地 |
| 状态 | 正常 / 3 日内到期 / 已到期 |
| 到期时间 / 剩余时长 | 用于判断是否需要续费 |
| 备注 | 自定义标记，便于区分用途 |

 

## **获取代理参数**

在 IP 列表中找到目标 IP，点击「复制」即可获取代理参数。代理参数为可直接复制的完整代理 URL。

## **搜索与筛选**

- 单个搜索：在搜索框输入IP或代理参数即可定位。
- 批量搜索：点击搜索框弹出批量搜索弹窗，每行一条，支持输入IP、代理参数等，一次搜索多条。
- 筛选：支持按国家/地区、状态筛选。

## **备注管理**

可为每条 IP 添加备注（如店铺名、账号用途），方便多账号管理时快速区分。支持单个或批量编辑备注。
