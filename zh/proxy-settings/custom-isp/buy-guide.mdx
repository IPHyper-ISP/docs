---
title: "IPHyper选购指南 "
---

本指南带你一步步完成定制静态住宅 IP 的订购，从选择 IP 类型到付款完成，全程跟着界面操作即可，最快几分钟就能拿到可用的 IP。

定制静态住宅 IP 是优质独享静态 IP，支持选择带宽配置，适合对网络性能有较高要求的业务场景，起价低至 3.2\$/月。

## **第一步：进入订购页面**

登录管理面板后，在侧边栏找到「静态住宅 IP」并点击进入。也可以直接在官网首页，点击「定制静态住宅 IP」卡片下方的「立即购买」按钮跳转。

## **第二步：选择 IP 类型**

IPHyper 提供两种 IP 类型，下单前先想清楚要哪种：

- 原生（Native）：来源于真实家庭宽带的本地用户网络，来源真实、稳定性更高，适合对账号安全要求较高的场景。
- 广播（Broadcast）：基于服务器网络分配的住宅 IP，成本更低，适合预算优先、对稳定性要求相对宽松的场景。

## **第三步：选择地区、运营商和网段**

选择 IP 的归属地区，支持地区级筛选，可按国家 / 地区，运营商筛选定价。相交于标准静态住宅IP，定制静态住宅IP对于网段选择也有不同的方式，网段支持两种方式：

- 随机网段：由系统自动分配，下单更快。
- 自选网段：可指定更细的网段，适合对 IP 段有特定要求的场景。

右侧摘要面板会实时显示当前选择的地区、数量与总价，方便随时核对。

## **第四步：选择带宽配置**

这是定制版与标准版的主要区别。根据业务的并发量级选择15-35Mbps带宽规格，带宽高达35Mbps。独享大带宽可轻松应对高并发访问。拿不准时，可先按业务预估的峰值并发选择，后续再按需调整。

## **第五步：确认有效期和数量**

确定购买数量与IP有效期（30天）。定制静态住宅IP不支持批量折扣。摘要面板会同步更新新增数量后的总价。

## **最后确定订单并付款**

核定订单摘要，确定业务场景、地区、带宽、数量、运营商、有效期与总价无误后，选择支付方式完成付款。

付款成功后，定制IP会分配到你的账户，可在IP列表中查看并使用。
