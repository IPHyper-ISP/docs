---
title: "IPHyper选购指南 "
---

本指南带你一步步完成标准静态住宅 IP 的订购，从选择 IP 类型到付款完成，全程跟着界面操作即可，最快几分钟就能拿到可用的 IP。

标准静态住宅 IP 为长效固定IP，定价友好，性价比突出；适合跨境电商店铺日常运营、账号管理等通用业场景，起价低至 3 \$/月。

## **第一步：进入订购页面**

登录管理面板后，在侧边栏找到「标准静态住宅 IP」并点击进入。也可以直接在官网首页顶部菜单栏点击「标准静态住宅 IP」卡片跳转进入产品页面购买。

## **第二步：选择 IP 类型**

IPHyper 定制静态住宅IP，仅提供原生IP。

原生IP源自真实家庭宽带的本地用户网络，来源真实、稳定性更高，适合对账号安全要求较高的场景。

## **第三步：选择地区和运营商**

选择 IP 的归属地区，支持按国家 / 地区，运营商筛选定价。标准静态不支持指定网段，系统会自动分配网段。

##  

## **第四步：选择有效期和数量**

确定购买数量与 IP 有效期，有效期可选 7 天 / 30 天。数量越多，批量折扣越高（见上方折扣表）。右侧摘要面板会同步显示折扣后的总价。

## **最后确认订单并付款**

核对订单摘要，确认地区、数量、有效期与总价无误后，选择支付方式完成付款。

付款成功后，IP 会分配到你的账户，可在 IP 列表中查看并开始使用。
