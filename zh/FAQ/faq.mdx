<AccordionGroup>
  <Accordion title="什么是 IPHyper？">
    我们是一家专业静态住宅IP服务商，为跨境电商、社媒运营及全球业务提供稳定纯净的静态住宅 IP 解决方案。
  </Accordion>

  <Accordion title="什么是静态住宅代理？">
    静态住宅代理是一种使用住宅网络 IP 地址的代理服务，IP 地址通常会在订阅周期内保持固定。适合跨境电商、社交媒体运营、广告营销及其他需要长期使用固定 IP 的业务场景。
  </Accordion>

  <Accordion title="IPHyper 提供哪些代理产品？">
    IPHyper 提供标准静态住宅 IP、定制静态住宅 IP 及 直播专线，满足跨境电商、社交媒体运营及直播推流等不同业务需求。
  </Accordion>

  <Accordion title="IPHyper 支持哪些代理协议？">
    IPHyper 的标准及定制静态住宅 IP 支持 HTTP 和 SOCKS5 两种代理协议，用户可以根据自己的软件、设备及业务需求选择合适的连接方式。
  </Accordion>
</AccordionGroup>
