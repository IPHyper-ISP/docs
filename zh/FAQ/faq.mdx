<AccordionGroup>
  <Accordion title="**什么是 IPHyper？**">
    我们是一家专业静态住宅IP服务商，为跨境电商、社媒运营及全球业务提供稳定纯净的静态住宅 IP 解决方案。
  </Accordion>

  <Accordion title="**什么是静态住宅代理？**">
    静态住宅代理是一种使用住宅网络 IP 地址的代理服务，IP 地址通常会在订阅周期内保持固定。适合跨境电商、社交媒体运营、广告营销及其他需要长期使用固定 IP 的业务场景。
  </Accordion>

  <Accordion title="**IPHyper 提供哪些代理产品？**">
    IPHyper 提供标准静态住宅 IP、定制静态住宅 IP 及 直播专线，满足跨境电商、社交媒体运营及直播推流等不同业务需求。
  </Accordion>

  <Accordion title="**IPHyper 支持哪些代理协议？**">
    IPHyper 的标准及定制静态住宅 IP 支持 HTTP 和 SOCKS5 两种代理协议，用户可以根据自己的软件、设备及业务需求选择合适的连接方式。
  </Accordion>

  <Accordion title="**IPHyper 是否支持指定 IP 网段？**">
    支持。IPHyper 定制静态住宅 IP 提供指定网段选项，您可以根据业务需求选择合适的 IP 资源，具体可选范围以实际产品配置为准。
  </Accordion>

  <Accordion title="**IPHyper 的代理服务是否有流量限制？**">
    标准静态住宅 IP 和定制静态住宅 IP 均采用不限流量模式，使用期间无需额外担心流量消耗。TikTok 直播专线则根据具体方案配置流量。
  </Accordion>

  <Accordion title="**购买 IPHyper 产品后，如何开始使用？**">
    购买成功后，即可在控制台界面中查看已获取的代理 IP 信息及连接参数。根据所选代理协议，将相关信息配置到目标软件或设备中即可使用。
  </Accordion>

  <Accordion title="**如何确认代理 IP 是否连接成功？**">
    完成代理配置后，可以通过 IP 查询工具查看当前使用的 IP 地址、地理位置及运营商信息，确认是否与购买的代理资源相符。
  </Accordion>

  <Accordion title="**遇到代理连接失败的情况怎么办？**">
    请先检查代理地址、端口、用户名、密码及协议类型是否填写正确，并确认本地网络连接正常。如果仍无法连接，可以联系在线客服并提供相关错误信息，我们将协助您排查问题。
  </Accordion>
