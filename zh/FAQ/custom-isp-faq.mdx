<AccordionGroup>
  <Accordion title="**标准静态住宅 IP 和定制静态住宅 IP 有什么区别？**">
    - 标准静态住宅 IP： 提供 7 天和 30 天有效期，支持批量折扣及按运营商选择线路，默认带宽为美国 10M、其他地区 5M，适合常规住宅代理需求。
    - 定制静态住宅 IP： 有效期内仅供一个用户独享，支持指定网段、按需升级带宽，默认带宽为美国 15M、其他地区 10M，并针对 TikTok、Disney+、Netflix、YouTube、Amazon Prime、Reddit、ChatGPT 等业务场景进行适配。
  </Accordion>

  <Accordion title="**定制静态住宅 IP 在带宽方面有什么优势？**">
    定制静态住宅 IP 提供更高的默认独享带宽，最高可支持 35M 配置，并支持按需升级，满足高带宽及多任务并发等业务需求。
  </Accordion>

  <Accordion title="**选择“目标业务场景”有什么作用？**">
    定制静态住宅 IP 已针对 TikTok、Disney+、Netflix、YouTube、Amazon Prime、Reddit、ChatGPT 等业务场景进行适配验证。选择目标业务场景，有助于我们了解您的实际用途，为您提供更匹配的 IP 资源与配置方案。
  </Accordion>

  <Accordion title="**IPHyper 提供哪些客户支持服务？**">
    定制静态住宅IP默认支持 UDP 协议。可满足基于UDP协议的应用和服务连接需求，如流媒体加载、实时通讯等对延迟敏感的场景。
  </Accordion>

  <Accordion title="**为什么检测到的 IP 地理位置与购买地区不完全一致？**">
    不同 IP 检测平台使用的数据库及更新周期不同（通常为 7–30 天），因此检测结果可能存在差异，我们通常以 IPinfo 的检测结果作为参考。建议您通过多个 IP 检测平台交叉验证，若发现 IP 存在明显的跨区域差异，请在购买后的 24 小时内提供 IP 地址及检测截图，联系客服核查。
  </Accordion>
</AccordionGroup>
