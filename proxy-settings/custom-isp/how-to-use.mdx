The **Custom ISP Proxies** is a dedicated IP, assigned to a single user for the whole duration, so the network environment is cleaner and more stable. This guide takes you from viewing the IP list and getting proxy credentials to managing renewals, step by step.

## **View the IP List**

After a successful purchase, sign in to the dashboard and open “IP List” to view the details of each IP: 

| Field | Description |
| :-- | :-- |
| IP / Port | Proxy IPs and port |
| Proxy string | A complete proxy string you can copy directly |
| Country / Region | IP location |
| Status | Active / Expiring within 3 days / Expired |
| Expiry / Time left | Helps you judge whether renewal is needed |
| Note | Custom labels to easily distinguish usage |

 

## **Get Proxy Credentials**

Find the target IP in the IP list and click “Copy” to get its proxy credentials. The credentials are a complete proxy URL that you can copy directly.

IPHyper supports several proxy credential formats, so you can switch as needed:

The username is assigned automatically by the system, the hostname is the proxy ips, and the port is the access port. Refer to what the IP list actually shows.  

## Search and Filter 

- Single search: enter an IP or proxy credential in the search box to locate it.
- Bulk search: click the search box to open the bulk search dialog, enter one entry per line (IPs, proxy credentials, and more), and search several at once.
- Filter: filter by country/region and status.

## **Manage Notes**

You can add notes to each IP (e.g., store name, account purpose) for quick differentiation when managing multiple accounts. Single or bulk note editing is supported.
